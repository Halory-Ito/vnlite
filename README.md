# vnlite 🌸

**把你的视觉小说世界，装进口袋。**

vnlite 是 VNDB 的非官方移动客户端。从寻找下一部心仪作品，到整理收藏、记录游玩，再到跟着攻略走完喜欢的线路，都可以在这里慢慢完成。

支持简体中文与英文界面，适配手机、mini pad 和大屏平板。

## 📲 开始使用

前往 [GitHub Releases](https://github.com/Halory-Ito/vnlite/releases) 查看可用的安装包与发布说明。Android 用户可下载 APK 安装；有多个架构包时，请选择适合设备的版本。

打开应用即可浏览和搜索。需要管理 VNDB 清单时，在「我的」中进入账号页面，按引导创建并填写 [VNDB API Token](https://vndb.org/u/tokens)，授予相应的清单读取、写入权限。

> vnlite 是资料浏览与记录工具，不提供游戏本体下载或游戏运行功能。

## 🔎 下一部，想读什么？

- **随心发现**：从排行榜、最新评价、即将发售与最新上架里找灵感，也可以随机抽一部。
- **细细筛选**：按标签、厂商、原语言、平台、时长、开发状态和评分等条件缩小范围，再按人气、评分或发售日期排序。
- **不只搜作品**：也能查找制作人员、厂商与用户。用户搜索需要填写准确的用户名。
- **换个看法**：网格看封面，列表看信息；卡片显示哪些内容，由你决定。

## 📖 一部作品，慢慢了解

简介、角色、制作人员、发行版本、截图、关联作品、语录、讨论、攻略与外链，集中在作品详情里。

点开角色看看配音与登场作品，顺着制作人员找熟悉的名字，或翻翻其他玩家的评价与讨论。成人内容与剧透显示可以在设置中调整。

### 🧭 攻略陪你走完每条线路

攻略按「线路 → 结局 → 步骤」展开，可以逐条标记走过的步骤、勾选已达成的结局。开启攻略剧透保护后，隐藏内容需要点击才会显示。

攻略来自 [社区攻略仓库](https://github.com/Halory-Ito/vnlite-walkthrough-and-guide)，覆盖范围取决于社区贡献。已缓存的攻略可在离线时查看，清理攻略缓存时会保留已标记的攻略与进度。

## 📚 把喜欢的作品整理好

连接 VNDB 账号后，可以查看和编辑自己的清单，管理游玩状态、评分与标签。清单修改会提交到 VNDB，列表和网格的显示偏好也会记住。

本地收藏与浏览历史则让你更方便地找回看过的作品。

## 🎮 留下每一天的游玩足迹

记录游玩时段，查看时长图表与热力图，再给自己定一个每天的小目标，或今年想通关多少部的年度目标。

| 首页卡片     | 统计内容                                            |
| ------------ | --------------------------------------------------- |
| 今日游玩     | 本地游玩记录中的今日时长，以及每日目标进度          |
| 总游玩时长   | 本地游玩记录累计时长                                |
| 今年通关目标 | VNDB 清单中标记为已完成，且完成日期属于今年的作品数 |
| 通关总数     | VNDB 清单中所有标记为已完成的作品数，不限年份       |

### 🗓️ 想玩的新作，记在日历上

发售日历支持翻月、跳转年月、选择日期查看当天的作品，还能一键回到今天。看到期待的新作，可以通过系统日历创建提醒。

首页有哪些区域、按什么顺序出现，都可以在「我的 → 首页布局」中调整。

## 🎨 调成你喜欢的样子

内置 **11 套主题**，包括 Fate / Stay Night、AIR、Ever17、Little Busters! 等，也可以自己搭配主色、辅色与背景图。

- ☀️ 明亮、深色或跟随系统，每套主题都能切换。
- 🖼️ 从相册选择背景，调整位置、模糊与遮罩。
- 🫧 调整卡片透明度和图片圆角，让封面与背景更协调。
- 💎 底栏可选贴底、悬浮胶囊或液态玻璃，透明度、模糊与切换动画均可设置；液态玻璃还有独立的质感强度调节。
- 📱 手机轻松浏览，平板利用更宽的空间展示多列内容。

## ☁️ 换设备，也带上自己的记录

支持通过 **WebDAV、百度网盘、夸克网盘**备份与恢复本地数据，自定义头像与背景图也能随备份迁移。

VNDB 清单由 VNDB 账号管理，本地备份与云端清单各有用途。换设备前，记得先完成备份。

缓存管理可以查看不同类别的占用，按需清理作品信息、图片和攻略缓存。

### 🛠️ 本地开发

项目使用 Expo、React Native、TypeScript、HeroUI Native 与 Uniwind，包管理器为 Bun。

```bash
bun install
bun start
```

包含自定义原生依赖，调试时请使用对应的开发构建。

| 命令                          | 用途                                                                 |
| ----------------------------- | -------------------------------------------------------------------- |
| `bun run check`               | 类型、Lint、格式与 API、主题、布局、数据库冒烟检查；API 检查需要联网 |
| `bun test`                    | 运行测试文件                                                         |
| `bun run bundle:check`        | 验证 Android 资源导出                                                |
| `bun run build:android:dev`   | 使用 EAS 创建 Android 开发构建                                       |
| `bun run build:android`       | 使用 EAS 云构建 Android APK                                          |
| `bun run build:android:arm64` | 使用 EAS 云构建 arm64 Android APK                                    |
| `bun run build:ios:sim`       | 使用 EAS 云构建 iOS 模拟器包                                         |

业务代码按功能组织在 `src/features/`，路由位于 `src/app/`，公共组件、数据访问与主题分别放在 `src/components/`、`src/lib/` 和 `src/theme/`。
